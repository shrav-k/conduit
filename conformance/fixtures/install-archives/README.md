# Installation archives

Not binding. These are repository-authored bytes for the [archive vectors](../../language/archives/s1/case.yaml).
They contain Conduit's S1 filesystem contract documents and small deliberate variations. No
third-party artifact, executable server or dependency is included.

The Rust [generator](../../../reference-model/crates/conformance/examples/make_archives.rs)
reads the S1 filesystem documents, constructs POSIX USTAR members in sorted path order, and
compresses them with the locked flate2 Rust backend at level 9. Headers use mode 0644, zero
uid/gid/mtime and empty owner names; gzip has mtime zero, OS 255 and no filename. Two zero
blocks terminate the tar. The deliberately malformed fixtures are named `not-gzip` and
`not-tar`; traversal and link fixtures deliberately encode unsafe members. The generator
neither fetches nor executes anything.

From `reference-model/`, regenerate or verify every generated byte and its recorded SHA-256:

```sh
cargo run --release -p conduit-conformance --example make_archives
cargo run --release -p conduit-conformance --example make_archives -- --check
```

[digests.json](digests.json) records PKG-004's SHA-256 of each compressed archive. Each vector's
installation recipe separately states the expected digest; the wrong-digest case deliberately
states another. The S1 installation vector uses the three existing [S1 archives](../s1/README.md#computed-digests),
whose pins and ordinary documents also serve its snapshot baseline.

The profile reads USTAR regular files, directories, symbolic links and hard links, without GNU
or PAX extensions. Paths are UTF-8; hard links name an earlier regular file; at most forty link
expansions are permitted. Repeated paths replace earlier members, but a nonempty directory
cannot be replaced by a non-directory, and a non-directory cannot serve as a member's parent.
Malformed streams and unsupported dialect features reject under PKG-022; paths or links that
escape reject under MAN-014. Root document links are read through the same strict loader as
regular files; dangling document links reject under SUB-010. No extraction touches disk: the
core retains the virtual directory and file modes in the installed package's state.

The manifest-parent fixtures distinguish a regular file or missing component from a directory
before `..`; only the directory form can be read (MAN-011, SUB-010 and MAN-013). The
link-expansion fixtures require 39, 40 and 41 replacements from `conduit.yaml` to its regular
manifest, accepting the first two and rejecting the last under the profile's DL7 limit.
The escape vectors assert both the archive name and the offending member `escape` (MAN-014).
