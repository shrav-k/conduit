# Condensing the repository

Not binding. The [specification](../../../spec/README.md) alone binds. The owner asked to condense
historical documents that pollute agents' context, keeping every piece of relevant Conduit
information ([ruling 57](../ruling-57/README.md)). A condensation audit read every area and proposed
a [plan](plan.md), checked by four information-loss skeptics and a [critic](critic.md).

About 72% of the historical and tracking text can leave the tree once its relevant information is
extracted: `docs/proposals/` from 918k words to about 246k, the re-audit rounds from 255k to about
36k, `experiments/` from 980 files to 38, and `docs/AUDIT.md` from 23.6k words to about 7.3k. Git
keeps every removed version; an index of removed files links each to its last version.

The owner ruled its ten points in [ruling 58](../ruling-58/README.md). The work runs as Codex work
orders, each reviewed by the coordinator for lost content, in the plan's sequence, with the
critic's execution issues handled there.
