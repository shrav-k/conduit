"The pin" means the tag that fixes the build the S1 rerun measures. Each order holds one behavior and stays small, because large orders do not converge ([FR-264](findings/P01-work-orders-lanes.md#fr-264)). Batch 1's 18 orders, from S0b to 053, follow, with SO-A before 046a and SO-B before batch 1 builds on outcomes.

**Place.** *Before*: the pin, or a batch-1 order on the way to it, waits on this order, or the order has a deadline. *Beside*: dispatched before the pin while the serial core chain waits, but nothing waits on it. *After*: after the pin.

**Checks named once.** The *docs checks* are `python3 tools/check_docs.py` and `git diff --check`. The *spec checks* are `python3 tools/check_schemas.py`, `python3 tools/set_names.py --check`, `python3 tools/check_rulings.py` and the docs checks. The *path and secret checks* are `python3 tools/check_private_paths.py` exiting 0 and the pull request's secret scan (#2) passing.
