# The owner's direction for the experiments, 2026-11-10

Not binding. The [specification](../../../spec/README.md) alone binds. The coordinator asked
the owner what only the owner can supply for the experiments that v0 needs
([ruling 47's list](../../../ROADMAP.md#the-experiment-program)), and records the answers here,
with what the coordinator does with each. Nothing here is a ruling on behavior.

| Item | The owner's answer | What follows |
| --- | --- | --- |
| A second machine, for S3 and A74 | A Windows computer, with Linux available if needed; anything may run on it. The connection is set up later | S3 and A74 wait for the connection. Whether the engine runs on Windows itself or in Linux there is decided then: the shell's runner kills process groups, which is Unix's |
| The shared service, for S2 | 1Password, with a test vault on the owner's real account. Also a shared filesystem, when several agents work on Conduit | S2's shared login is a 1Password service account limited to the test vault, so that the most it can reach is that vault. A73 uses the same vault |
| The real use, for A14 | Conduit itself: iterating on the project, several packages worked on at once, and coordinating work among agents. To be discussed in more detail | A14's week is Conduit used to build Conduit, which A78 begins: the work orders, each worker an Agent with a Conduit to its own working tree |
| The second providers, for S10 | 1Password as the second secret store, Docker as the second runtime, and Git as the package source once a public organization exists | A63's second providers are these. The package source waits for the organization |
| More accounts, for A5 | A second Claude and a second Codex account exist. Adding an account is to be tested through Conduit's own flow, on this machine | Each Codex and Claude Code Agent gets a home of its own, signed in through the client's own flow started by the engine, which finding 3-07 and experiment 010 also need. A5 then runs on the second accounts |
| Bypass, for A7 | The coordinator scripts the attempts. Nothing on this machine is off limits | Probes test whether a path can be reached, with planted markers where content must be shown; no credential is read or printed, by the standing rule |
| Cold readers, for the read after step 3 | The collaborators on the repository, who need written instructions | The coordinator writes the readers' instructions before the read starts |
| The public name | Open: "Conduit" is not available as an organization or a domain, so a variant such as ConduitInterface may be needed | Nothing in the build depends on it; `spec/names.yaml` and `tools/set_names.py` change every name together when it is chosen |
