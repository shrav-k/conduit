# Ruling 64: organization and repository

Status: **ruled by the owner on 2026-11-10** (plan-audit ruling 64). This is the record of a
ruling. Where it and the specification differ, the specification governs.

The owner asked for organizational and repository items to resolve. The coordinator put five:
pull request 14 (ruling 47), the public name, continuous integration, the name of
`reference-model/`, and the organization's own items. The owner: "1. Rebase and merge 2. Let's do
that investigation but it has to be a logical variation on conduit 3. Do this, but I can't yet
afford to pay if it costs credits 4. Rename to engine 5. Wait for name decision".

## The decisions

1. **Pull request 14** is rebased and merged: [ruling 47](../ruling-47/README.md) is recorded, with
   its public name and namespace open.
2. **The public name** is researched among logical variations on "Conduit", with the availability of
   a GitHub organization, a domain and package names checked; the owner chooses.
3. **Continuous integration**, on GitHub's standard runners, which are free for a public repository;
   nothing that costs credits.
4. **`reference-model/` is renamed `engine/`**: ruling 47 makes v0 the reference engine, which that
   directory holds.
5. **The organization's own items** (issue templates, code owners, branch protection) wait for the
   name.
