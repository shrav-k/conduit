# The logins and sign-in core for 048a

The contract and schema edits are live; no 038c patch is staged. This is a build handoff.

Build CTR-013's required account path and three hooks, distinct login names, and rejection
where a URL could match two logins under IFC-049. The scripted signIn fixture Type states
its logins and requires a string-or-null account path and all three hooks.

Compare client IDs across addresses at installation, registration and replacement, including
submissions held by a template or instance (SUB-008, SUB-009, PKG-029). Sibling Types,
versions and submissions at one address may share them. Only root confirms shared IDs at
install; REC-002 records precisely those confirmed IDs. Show logins at install and inspection.
Build the login the person asks for, one fixed-port login at a time (PND-010), IFC-049's URL
match, and its engine-authored message. No return implementation is needed for S1's local
browser: its program's own listener receives the redirect. PND-013 is built after 048b.
